# Isolated LongRange three-toggle method

- Production `pipeline` and `VideoOutpainting` trees are read-only in this experiment. Only the copied package under `source/ltx_outpaint` was patched. Original inference file SHA256 and unified diff: `patches/sha256_before_after.txt`, `patches/inference_experiment.patch`.
- Authoritative baseline identity is `pipeline/data/02_VideoOutPaint_4K_3840x2160/chunk/05/run.json`; baseline output is `05_VideoOutPaint_4K.mp4`. Effective settings are copied into `configs/effective_baseline_settings.json`. The stale adapter default in `inference_4k.yaml` is overridden by baseline's explicit checkpoint argument.
- Independent CLI toggles: `--rebase-temporal-position`, `--use-latent-carry`, `--generated-prefix-strength`. All three OFF means original `sample_chunk` call path, positions, RGB VAE re-encode, side amplitude, and metrics unchanged. The first selected chunk must begin from a baseline RGB seed because no earlier experimental final latent exists.
- Rebase skips only the absolute seconds added to model `state.positions`; global anchor decode, per-chunk noise seed (`71634910 + global_start`), and emitted indices remain absolute.
- Carry is taken from the final post-Euler state after the scheduler's sigma=0 final step, after removing conditioning tokens and unpatchifying, before VAE decode. Exactly last three `[1,128,3,68,120]` BF16 latent temporal slices are persisted and directly loaded into the next chunk. The center anchor latent box is overwritten by the current chunk's independent exact anchor encoding (hybrid carry). The full RGB output remains committed in lossless uint8 segments and a 24-fps H.264 window MP4.
- A native conditioning strength of 0.8 is *not* used: upstream `VideoConditionByMask(strength=0.8)` would set `denoise_mask=0.2`, contrary to the fixed-prefix requirement. Instead, left/right prefix latent values are multiplied by 0.8. Their known mask, denoise mask=0, timestep=0, and visible RGB prefix remain fixed. This is an amplitude-based approximation to lower conditioning influence, not a calibrated 20% attention reduction. Center anchor box stays at factor 1.0.
- C21 first prefix is reconstructed from the last 17 frames of baseline C20's pre-MP4 RGB24 segment because the rolling FP32 prefix file was overwritten later by the completed full baseline run. That quantization confounds strict bitwise baseline equivalence for C21, though later C22/C23 use experimental clean latent carry. Do not attribute every difference to the three toggles alone.
- Tests: original CPU anchor/known-mask regression suite `8 passed`; experiment tests `2 passed` including hybrid carry and temporal position delta. Logs under `logs/`.
- Rollback: stop only this experiment's process if still running, then remove or archive this one experiment folder. No production source patch to reverse; original `VideoOutpainting/main/src/ltx_outpaint/inference.py` was never changed.
